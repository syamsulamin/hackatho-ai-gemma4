## Project Overview

Brebes Go AI adalah aplikasi berbasis AI (Gemma) yang membantu wisatawan menemukan destinasi wisata, kuliner, dan UMKM terbaik di Kabupaten Brebes menggunakan bahasa alami.

Target hackathon adalah menghasilkan MVP yang dapat selesai dalam waktu kurang dari 3 jam.

Aplikasi harus sederhana, mudah digunakan, dan menunjukkan penggunaan AI sebagai fitur utama.

Goal: Prototype selesai + AI berjalan + submit. hanya satu 

## Techstack
Nuxt 4
TypeScript
Nuxt UI
Tailwind
Gemma API
Local JSON Dataset

Tidak perlu (pada fase Hackathon MVP):
* Login
* Database
* Supabase
* Admin
* CRUD
* Payment
